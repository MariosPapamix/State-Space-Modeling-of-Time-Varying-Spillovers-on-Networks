# When Are Time-Varying Spillovers on a Network Identified?

Code, data, and paper source for arXiv:2512.18584 (v2). Every number, table, and
figure in the paper is generated by the scripts in `code/` from the files in
`data/` plus two public JHU CSSE files downloaded at run time.

## Layout
- `code/`   sixteen generating scripts + `nb_filter.py` (module) + `verify_theorems.py`
- `code/out/`  JSON result files as used for the submitted tables
- `data/`   `crime.csv`, `neighborhood.mtx` (Chicago; from the public repository
  cited in the paper), `uid_lookup.csv` (JHU population lookup).
  `covid_us.csv` (~17 MB) is **not** shipped: `covid.py`/`covid2.py` download it.

## Requirements
Python >= 3.10; `numpy` (>= 1.22; 2.x supported), `scipy`, `pandas`,
`matplotlib` (figures only). No other dependencies. Fixed seeds throughout.

## Reproduce everything
```bash
python3 -m venv venv && . venv/bin/activate
pip install numpy scipy pandas matplotlib
cd code
python3 verify_theorems.py        # ~3 min  -> "49 total, 0 failures"
python3 sim_study.py              # S1-S3          (~10 min)
python3 addendum_sim.py           # S4-S6, S1b-c   (~10 min)
python3 sim_extra.py              # S1d, S4 ext, S7 (~12 min)
python3 chicago.py                # fits, placebo, S-scan (~8 min)
python3 unified_eval.py           # Tables 3-5, leak-free (~6 min)
python3 addendum_chicago.py       # original tests, NB layer (~5 min)
python3 final_model.py            # final-model diagnostics + stratified test (~6 min)
python3 benchmarks.py             # external benchmarks + self-tests (~8 min)
python3 postprocess_tables.py     # renders unstable means as `div.', adds plug-in row (seconds)
python3 covid.py && python3 covid2.py   # Texas (downloads JHU; ~12 min)
python3 tvcompare.py              # rolling/expanding-window, spline and score-driven competitors, calibration, lead-lag figure (~1 min)
python3 measles.py                # third dataset (Weser-Ems measles) + cross-check vs native R fits (~20 s; reads shipped CSVs)
python3 make_figures.py && python3 make_tables.py
```
Total: under an hour on a laptop. Monte Carlo entries reproduce within the
seed-to-seed SDs stated in the paper (e.g. 0.07 for the h=1 log-score gain).
